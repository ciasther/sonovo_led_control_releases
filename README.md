## 📦 Downloads

The latest release contains the distributable files for both supported platforms:

| File | Purpose |
| --- | --- |
| [`NanovoWindowsLedSetup.exe`](https://github.com/ciasther/sonovo_led_control_releases/releases/latest) | Signed Windows installer |
| `NanovoWindowsLedSetup.exe.sha256` | Windows installer checksum |
| [`linux-led-control-cli`](https://github.com/ciasther/sonovo_led_control_releases/releases/latest) | Linux service binary |
| `linux-led-control-cli.sha256` | Linux binary checksum |

➡️ [Open the latest release](https://github.com/ciasther/sonovo_led_control_releases/releases/latest)

Windows updates are started from the tray menu: **Check for updates**.
Linux updates are installed by running `install.sh` again.
